1 Que es Python?

💡
Python es un lenguaje de programacion creado en 1991. Se caracteriza por ser facil de leer, con una sintaxis limpia que se parece al ingles. Se usa en inteligencia artificial, desarrollo web, analisis de datos y hasta en la NASA!

A diferencia de HTML (que solo describe como se ve una pagina), Python ejecuta instrucciones: puede hacer calculos, tomar decisiones, repetir tareas y mucho mas.

2 La funcion print()

La primera funcion que aprendemos es print(). Sirve para mostrar texto en pantalla:

print("Hola, mundo!")
print("Estoy aprendiendo Python")

Todo lo que va entre comillas (simples o dobles) se llama string (cadena de texto). Las comillas le dicen a Python: "esto es texto, no codigo".

3 Variables y tipos de datos

Una variable es como una caja etiquetada donde guardamos informacion. En Python se crean simplemente asignando un valor:

nombre = "Ana"         # string (texto)
edad = 16              # int (entero)
altura = 1.65          # float (decimal)
print(nombre)
print(edad)
