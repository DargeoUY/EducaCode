1 La funcion input()

⌨️
La funcion input() permite que el programa le pregunte algo al usuario y espere su respuesta. Todo lo que el usuario escribe se guarda como string (texto).
nombre = input("Como te llamas? ")
print("Hola, " + nombre)

2 Conversion de tipos

Como input() siempre devuelve texto, si queremos hacer calculos necesitamos convertir el texto a numero:

edad_texto = input("Cuantos anos tenes? ")
edad = int(edad_texto)
print("El ano que viene tendras", edad + 1)

3 Operadores aritmeticos

Python puede hacer calculos matematicos:

a = 10
b = 3
print(a + b)   # 13 (suma)
print(a - b)   # 7  (resta)
print(a * b)   # 30 (multiplicacion)
print(a / b)   # 3.333... (division)
print(a // b)  # 3 (division entera)
print(a % b)   # 1 (resto o modulo)
