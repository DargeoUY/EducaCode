Aprendiendo for y while para repetir tareas

1 for con range()

🔁
El bucle for repite un bloque de codigo una cantidad determinada de veces. range(n) genera los numeros del 0 al n-1.
for i in range(5):
    print("Vuelta numero", i)
for i in range(1, 6):
    print(i)   # Imprime 1, 2, 3, 4, 5

2 while

El bucle while repite mientras una condicion sea verdadera:

contador = 0
while contador < 5:
    print("Contador:", contador)
    contador = contador + 1

3 break y continue

🛑
break

Detiene el bucle inmediatamente.

⏭
continue

Salta a la siguiente vuelta del bucle.
