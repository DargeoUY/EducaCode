Python Nivel 3: Tomando Decisiones Nivel 3

Aprendiendo a usar if, elif y else

1 if / elif / else

🔀
En Python, las decisiones se escriben con if (si), elif (sino si) y else (sino). La indentacion (espacios al inicio) es obligatoria.
edad = int(input("Cuantos anos tenes? "))
if edad >= 18:
    print("Sos mayor de edad")
elif edad >= 13:
    print("Sos adolescente")
else:
    print("Sos nino/a")

2 Operadores de comparacion

==  igual a          !=  distinto de
>   mayor que        <   menor que
>=  mayor o igual    <=  menor o igual

3 Operadores logicos

if edad >= 18 and tiene_permiso:
    print("Puede conducir")
