Diseño Web CSS Nivel 2 — Ejercicios Práctica

Copiá cada ejercicio en tu cuaderno y resolvelo

1 Capas del Box Model

Dibujá en tu cuaderno el modelo de cajas y nombrá las 4 capas de adentro hacia afuera. Escribí al lado de cada capa qué propiedad CSS la controla.

2 Margin vs Padding

Escribí la regla CSS para cada caso:

A) Un div con 20px de margen externo en todos los lados.
B) Un div con 15px de relleno interno arriba y abajo, y 30px a los costados.

3 Bordes creativos

Escribí tres reglas CSS para tres divs diferentes:

A) Borde sólido azul de 3px.
B) Borde discontinuo (dashed) verde de 2px.
C) Borde con puntitos (dotted) rojo de 1px con esquinas redondeadas (8px).

4 Dimensiones

Respondé en tu cuaderno:

📝
A) ¿Qué diferencia hay entre width: 300px y width: 50%?
B) ¿Qué pasa si no especificás height y solo ponés contenido adentro?

5 Maquetá una tarjeta

Escribí el CSS para crear una tarjeta (card) con estas características: ancho 300px, padding 20px, borde sólido gris de 1px, esquinas redondeadas de 10px y margen inferior de 15px.
