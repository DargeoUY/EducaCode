for, while y arrays básicos

1 Bucles: repitiendo tareas

💡
Un bucle (loop) es una estructura que repite un bloque de código varias veces. Son fundamentales para procesar listas de datos, repetir operaciones y evitar escribir el mismo código muchas veces. JavaScript tiene varios tipos de bucles: for, while y do...while.

En lugar de escribir 100 líneas de console.log() para contar del 1 al 100, un bucle lo hace en 3 líneas. ¡Esa es su magia!

2 El bucle for

El bucle for es el más usado cuando sabemos cuántas veces queremos repetir algo. Su estructura tiene tres partes:

🏁
Inicio

Se ejecuta una vez al empezar: let i = 0;

🔍
Condición

Se verifica antes de cada vuelta: i < 10;

➕
Incremento

Se ejecuta al final de cada vuelta: i++

Ejemplo: contar del 1 al 10

for (let i = 1; i <= 10; i++) {
    console.log("Número: " + i);
}
// Muestra en consola:
// Número: 1
// Número: 2
// ...
// Número: 10

i++ es lo mismo que i = i + 1: incrementa el valor en 1.

3 El bucle while

El bucle while repite un bloque mientras una condición sea verdadera. Se usa cuando no sabemos exactamente cuántas repeticiones necesitaremos.

⚠️
¡Cuidado con los bucles infinitos! Si la condición del while nunca se vuelve falsa, el bucle se ejecutará para siempre y el navegador se trabará. Siempre asegurate de que algo dentro del bucle modifique la condición.

Ejemplo:

let contador = 1;

while (contador <= 5) {
    console.log("Vuelta número: " + contador);
    contador++;  // ¡Fundamental! Sin esto, bucle infinito
}
// Muestra: Vuelta número: 1, 2, 3, 4, 5

4 Arrays: listas de datos

Un array (o arreglo) es una variable que puede guardar múltiples valores ordenados. Se define con corchetes [] y cada elemento tiene un índice que empieza en 0.

Ejemplo de array:

let frutas = ["manzana", "banana", "naranja"];

console.log(frutas[0]);   // manzana (primer elemento, índice 0)
console.log(frutas[1]);   // banana  (segundo elemento, índice 1)
console.log(frutas[2]);   // naranja (tercer elemento, índice 2)
console.log(frutas.length); // 3 (cantidad de elementos)

Recorrer un array con for:

let frutas = ["manzana", "banana", "naranja"];

for (let i = 0; i < frutas.length; i++) {
    console.log("Fruta " + i + ": " + frutas[i]);
}
// Muestra:
// Fruta 0: manzana
// Fruta 1: banana
// Fruta 2: naranja

La propiedad .length devuelve la cantidad de elementos del array. Es muy útil para los bucles.
