Eventos, onclick y getElementById

1 Eventos: reaccionando al usuario

💡
Un evento es algo que sucede en la página: un clic, una tecla presionada, mover el mouse, cargar la página. El navegador está constantemente "escuchando" estos eventos y JavaScript nos permite reaccionar a ellos.

El evento más común es onclick, que se dispara cuando el usuario hace clic en un elemento. Otros eventos importantes son onmouseover (pasar el mouse), onkeydown (presionar tecla) y onload (cuando la página termina de cargar).

Ejemplo de onclick:

<button onclick="alert('¡Hiciste clic!')">Haceme clic</button>

2 getElementById(): encontrando elementos

document.getElementById("id") es uno de los métodos más importantes de JavaScript. Permite encontrar cualquier elemento HTML mediante su atributo id y manipularlo desde el código.

Ejemplo: cambiar texto al hacer clic

<p id="mensaje">Texto original</p>
<button onclick="cambiarTexto()">Cambiar</button>

<script>
function cambiarTexto() {
    document.getElementById("mensaje").innerHTML = "¡Texto cambiado!";
}
</script>

El id debe ser único en toda la página. No puede haber dos elementos con el mismo id.

3 Modificando contenido

Una vez que obtenemos un elemento con getElementById(), podemos cambiar su contenido con dos propiedades:

📄
.innerHTML

Lee o escribe el contenido HTML del elemento. Permite incluir etiquetas: elemento.innerHTML = "<strong>Negrita</strong>";

📝
.textContent

Lee o escribe solo el texto plano del elemento. Las etiquetas HTML no se interpretan: elemento.textContent = "Texto seguro";

Ejemplo práctico: botón que cambia un título

<h1 id="titulo">Bienvenido</h1>
<button onclick="cambiarTitulo()">Cambiar título</button>

<script>
function cambiarTitulo() {
    let titulo = document.getElementById("titulo");
    titulo.innerHTML = "¡Hola Mundo!";
}
</script>

4 Modificando estilos desde JS

JavaScript también puede cambiar la apariencia visual de los elementos mediante la propiedad .style. Esto permite crear páginas dinámicas que reaccionan al usuario.

🎨
.style.color

Cambia el color del texto: elemento.style.color = "red";

🖼️
.style.backgroundColor

Cambia el color de fondo: elemento.style.backgroundColor = "yellow";

📏
.style.fontSize

Cambia el tamaño de letra: elemento.style.fontSize = "24px";

Ejemplo: botón que cambia el color de fondo

<div id="caja" style="width:200px;height:200px;background:blue;"></div>
<button onclick="cambiarColor()">Cambiar a rojo</button>

<script>
function cambiarColor() {
    document.getElementById("caja").style.backgroundColor = "red";
}
</script>
