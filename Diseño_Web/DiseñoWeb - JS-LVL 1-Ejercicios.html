2 console.log() en acción

Escribí un bloque de código que haga lo siguiente usando console.log(). Después, explicá qué verías en la consola (F12).

let materia = "Pensamiento Computacional";
let año = 2026;
console.log("Estoy en la clase de " + materia);
console.log("Año: " + año);
console.log("Fin del programa");

Pregunta: ¿En qué orden se mostrarían estos mensajes en la consola?

5 Asignación vs. comparación

Mirá este código y respondé en tu cuaderno: ¿qué hace cada línea? ¿Hay algún error?

let x = 10;
let y = 5;
x = y;           // ¿Qué hace esta línea?
console.log(x);  // ¿Qué valor muestra?
// Ahora imaginá este otro código:
let a = 10;
let b = 5;
console.log(a === b);  // ¿Qué muestra? ¿Por qué?

Explicá con tus palabras la diferencia entre = (asignación) y === (comparación).
