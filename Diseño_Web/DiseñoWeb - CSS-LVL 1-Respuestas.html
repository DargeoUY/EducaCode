1 Selectores CSS

A) p { color: blue; }
B) .destacado { background-color: yellow; }
C) #encabezado { border: 1px solid black; }

Criterios: A usa selector de etiqueta sin punto ni numeral. B usa punto antes del nombre de clase. C usa numeral antes del id.

2 Colores en CSS

/* Forma 1: nombre — simple y legible, ideal para colores básicos */
color: red;

/* Forma 2: hexadecimal — preciso, el más usado en desarrollo web */
color: #ff0000;

/* Forma 3: rgb — útil cuando necesitás transparencia con rgba() */
color: rgb(255, 0, 0);

Criterios: el estudiante debe nombrar las tres formas y dar un ejemplo válido de cada una. Valorar si explica cuándo usar cada una.

3 Propiedades de texto

p {
    font-family: Arial, sans-serif;
    font-size: 18px;
    text-align: center;
    color: #333;
}

Criterios: debe incluir las 4 propiedades exactas. sans-serif como respaldo en font-family es un plus.

4 ¿Dónde va el CSS?

Las dos formas principales son: 1) CSS interno: dentro de la etiqueta <style> en el <head> del HTML. 2) CSS externo: en un archivo separado con extensión .css vinculado con <link rel="stylesheet" href="estilos.css"> en el <head>. El método externo es el más recomendado porque separa el diseño del contenido y permite reutilizar los mismos estilos en varias páginas.

5 Selector de clase vs ID

Clase (.): se puede aplicar a múltiples elementos en la misma página. Ideal para estilos reutilizables (ej: botones, tarjetas, destacados). ID (#): debe ser único en toda la página (solo un elemento puede tener ese id). Ideal para secciones específicas (ej: #encabezado, #barra-lateral). En CSS, el ID tiene mayor especificidad que la clase, por lo que sus estilos prevalecen si hay conflicto.
