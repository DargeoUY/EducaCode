Diseño Web Nivel 2 — Respuestas Docente

Clave de corrección para los ejercicios

🔒 SOLO DOCENTE — Respuestas del Nivel 2.

1 Crear un enlace

<a href="https://www.google.com">Ir a Google</a>

El atributo href es obligatorio. Sin él, el enlace no funciona.

2 Agregar una imagen

<img src="foto.jpg" alt="Mi foto de perfil">

<img> es huérfana (no se cierra). src indica la ruta del archivo, alt el texto alternativo.

3 Lista ordenada

<ol>
  <li>Poner yerba en el mate</li>
  <li>Calentar el agua</li>
  <li>Cebar el mate</li>
</ol>

Usa <ol> para orden automático (1, 2, 3). Cada ítem va en <li>.

4 ¿Cuál es la diferencia?

<ul> = lista desordenada (viñetas •). <ol> = lista ordenada (números 1,2,3). En común: ambas usan <li> para cada ítem.

5 Lista desordenada

<ul>
  <li>Manzana</li>
  <li>Banana</li>
  <li>Naranja</li>
</ul>

Criterios: 3 frutas distintas, cada una en su <li>, todo dentro de <ul>.
