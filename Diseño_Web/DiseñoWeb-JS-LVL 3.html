if, else y comparaciones

1 Condicionales: decisiones en código

💡
if / else permite que el programa tome decisiones: ejecuta un bloque de código si se cumple una condición, y otro bloque diferente si no se cumple. Es como un "si... entonces... si no..." de la vida real.

La estructura básica es: if (condición) { ... } else { ... }. La condición debe ser algo que se pueda evaluar como verdadero o falso.

Ejemplo:

let edad = 18;

if (edad >= 18) {
    console.log("Sos mayor de edad");
} else {
    console.log("Sos menor de edad");
}
// Como edad es 18, se mostrará: "Sos mayor de edad"

2 Operadores de comparación

Para escribir condiciones, necesitamos comparar valores. Estos son los operadores de comparación en JavaScript:

🎯
=== (igualdad estricta)

Compara valor y tipo: 5 === 5 es true, pero 5 === "5" es false.

❌
!== (distinto)

Verifica que sean diferentes: 5 !== 3 es true, 5 !== 5 es false.

⬆️
> y < (mayor / menor)

10 > 5 es true. 3 < 1 es false.

📊
>= y <= (mayor o igual / menor o igual)

5 >= 5 es true. 4 <= 3 es false.

⚠️
¡No confundir! === compara (¿son iguales?), mientras que = asigna (guardá este valor). Son operadores completamente distintos.

3 Condiciones compuestas

Podemos combinar varias condiciones usando operadores lógicos:

🔗
&& (AND - "y")

Ambas condiciones deben ser true: if (edad >= 18 && tieneLicencia) { ... }

🔀
|| (OR - "o")

Al menos una condición debe ser true: if (dia === "sábado" || dia === "domingo") { ... }

Ejemplo práctico:

let nota = 8;
let asistencia = 85;

if (nota >= 6 && asistencia >= 80) {
    console.log("¡Aprobaste la materia!");
} else {
    console.log("No cumplís los requisitos.");
}
// Muestra: "¡Aprobaste la materia!" (ambas condiciones son true)

4 if / else if / else: múltiples caminos

Cuando hay más de dos alternativas, usamos else if para agregar condiciones intermedias. Se evalúan en orden: apenas una es verdadera, las demás se ignoran.

Ejemplo: sistema de calificaciones

let nota = 75;

if (nota >= 90) {
    console.log("Excelente");
} else if (nota >= 70) {
    console.log("Bien");
} else if (nota >= 60) {
    console.log("Regular");
} else {
    console.log("A mejorar");
}
// Muestra: "Bien" (75 >= 70, pero 75 no >= 90)

El else final (sin condición) es el "plan B": se ejecuta si ninguna de las condiciones anteriores se cumplió.
