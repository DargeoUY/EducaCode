Diseño Web Nivel 4 — Respuestas Docente

Clave de corrección para los ejercicios

🔒 SOLO DOCENTE — Respuestas del Nivel 4.

1 Crear un formulario

<form>
  <input type="text" placeholder="Escribí algo">
  <button type="submit">Enviar</button>
</form>

Criterios: todo debe estar dentro de <form>. Debe tener al menos un <input> y un <button>.

2 Tipo de campo

A) type="password" (enmascara con puntos). B) type="number" (solo números). C) type="text" (texto común, es el valor por defecto).

3 El atributo placeholder

Muestra un texto gris de sugerencia o pista dentro del campo antes de que el usuario escriba. Desaparece al empezar a tipear. Ejemplo: <input type="text" placeholder="Ingresá tu nombre">

4 Input numérico

<input type="number" placeholder="Ingresá tu edad">

El navegador solo permitirá ingresar dígitos numéricos y bloqueará las letras.

5 Contenedor del formulario

La etiqueta obligatoria es <form>. Sin ella, el botón de envío no sabe qué datos recolectar ni a dónde enviarlos. Los inputs quedarían sueltos sin funcionalidad de envío.
