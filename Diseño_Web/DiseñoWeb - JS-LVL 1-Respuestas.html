3 Usando alert() y prompt()

alert("¡Hola! Vamos a calcular tu año de nacimiento.");
let edad = prompt("¿Cuántos años tenés?");
let añoNacimiento = 2026 - edad;
alert("Naciste aproximadamente en el año " + añoNacimiento);

Criterios: usar alert() para mensajes y prompt() para capturar entrada del usuario. La variable edad debe guardarse con let. El cálculo es 2026 - edad.

4 Identificando tipos de datos

A) string | B) number | C) boolean | D) string (tiene comillas) | E) number | F) boolean | G) string | H) number | I) string

Pregunta extra: Sí, hay diferencia. true sin comillas es un boolean (verdadero/falso). "true" con comillas es un string (texto). No son lo mismo: true === "true" es false porque son de distinto tipo.

5 Asignación vs. comparación

x = y; es una asignación: guarda el valor de y (que es 5) dentro de x. Después de esa línea, x vale 5 (su valor original de 10 se pierde). console.log(x) muestra 5.

console.log(a === b); muestra false porque === compara los valores: 10 no es igual a 5.

Diferencia clave: = asigna/guarda un valor en una variable. === compara dos valores y devuelve true o false sin modificar nada.
