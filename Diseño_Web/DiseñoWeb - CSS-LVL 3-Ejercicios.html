Diseño Web CSS Nivel 3 — Ejercicios Práctica

Copiá cada ejercicio en tu cuaderno y resolvelo

1 Contenedor Flex

Escribí el CSS necesario para convertir un elemento en contenedor flex y explicá qué efecto tiene sobre sus hijos directos.

2 Dirección del flujo

Escribí tres reglas CSS para tres contenedores flex diferentes:

A) Items en fila horizontal (valor por defecto).
B) Items en columna vertical.
C) Items en fila horizontal pero en orden inverso (de derecha a izquierda).

3 Alineación horizontal

Explicá en tu cuaderno qué hace cada uno de estos valores de justify-content y dibujá un esquema simple para cada uno:

📝
flex-start, center, space-between y space-around. Usá 3 cajitas como ejemplo.

4 Alineación vertical

Escribí el CSS para un contenedor flex de 400px de alto que centre sus items tanto horizontal como verticalmente. Este es el "centrado perfecto".

5 Navbar con Flexbox

Escribí el CSS para crear una barra de navegación horizontal con las siguientes características:

- Contenedor flex con items distribuidos con espacio entre ellos.
- Los items deben estar centrados verticalmente.
- Fondo oscuro (#333) y texto blanco.
