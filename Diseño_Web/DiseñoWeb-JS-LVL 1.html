Variables, console.log y alert

1 ¿Qué es JavaScript?

💡
JavaScript (JS): Es un lenguaje de programación que da vida a las páginas web. Se ejecuta directamente en el navegador del usuario y permite crear interactividad, animaciones y lógica. No es Java: son lenguajes completamente diferentes, solo comparten parte del nombre por razones históricas.

Mientras que HTML define la estructura y CSS el estilo, JavaScript define el comportamiento de una página web. Es lo que permite que un botón haga algo al hacer clic, que un formulario valide datos, o que un juego funcione en el navegador.

2 Variables: guardando información

Una variable es como una caja etiquetada donde guardamos un valor para usarlo después. En JavaScript moderno se declaran con let (puede cambiar) o const (no puede cambiar).

📝
string (texto)

Texto entre comillas: let nombre = "Ana";

🔢
number (número)

Números sin comillas: let edad = 16;

✅
boolean (verdadero/falso)

Solo dos valores: let activo = true;

⚠️
Importante: En JavaScript, el signo = es asignación (guardar un valor), NO es igualdad. Para comparar si dos cosas son iguales usamos ===.

Ejemplo de variables:

let nombre = "Lucía";       // string
let edad = 17;              // number
let esEstudiante = true;    // boolean
const PI = 3.1416;          // constante, no cambia

nombre = "Martín";          // let permite cambiar
// PI = 3;                  // ¡Error! const no se puede modificar

3 console.log(): viendo lo que pasa

console.log() es una herramienta fundamental para programar. Muestra mensajes en la consola del navegador, que se abre presionando la tecla F12 y seleccionando la pestaña "Consola". Es como un diario donde el programa escribe lo que está pasando.

Ejemplo:

let nombre = "Carlos";
let edad = 15;

console.log("Hola mundo");
console.log("El nombre es: " + nombre);
console.log("Edad: " + edad);
// En la consola del navegador (F12) se verá:
// Hola mundo
// El nombre es: Carlos
// Edad: 15

La consola es indispensable para detectar errores y entender qué está haciendo nuestro código. ¡Acostumbrate a usarla!

4 alert(): mensajes al usuario

alert() muestra una ventana emergente en el navegador con un mensaje. Es útil para pruebas rápidas y para mostrar información importante al usuario, aunque en sitios web modernos se prefieren métodos menos invasivos.

Ejemplo:

alert("¡Bienvenido a mi página!");

let nombre = prompt("¿Cómo te llamás?");
alert("Hola " + nombre + ", ¡qué bueno verte!");

También existe prompt(), que le pide al usuario que ingrese un texto y lo devuelve para guardarlo en una variable.
