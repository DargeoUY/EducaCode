Clave de corrección para los ejercicios de CSS Nivel 4

🔒 SOLO DOCENTE — Respuestas del CSS Nivel 4.

1 Mobile-first

Mobile-first significa diseñar y programar primero la versión para pantallas chicas (celulares) y luego, usando media queries con min-width, ir agregando estilos para pantallas más grandes. Se recomienda porque: (1) obliga a priorizar el contenido esencial, (2) mejora el rendimiento en dispositivos móviles, (3) es más fácil escalar hacia arriba que recortar hacia abajo, y (4) la mayoría del tráfico web actual viene de celulares.

2 Media Queries

/* Estilos base (mobile-first): fondo blanco */
body {
    background-color: #ffffff;
}

/* Tablets y escritorio (pantallas mayores a 600px) */
@media (min-width: 601px) {
    body {
        background-color: #f0f0f0;
    }
}

Criterios: enfoque mobile-first: el estilo base es para móvil y la media query expande a escritorio. También es válido el enfoque inverso con max-width. Debe usar la sintaxis correcta de @media.

3 Unidades relativas

A) vw (viewport width) es el 1% del ancho de la ventana del navegador. Sirve para hacer elementos que se adapten al ancho visible. Ej: width: 50vw; ocupa la mitad de la pantalla. B) em es relativa al tamaño de fuente del elemento padre; rem es relativa al tamaño de fuente del elemento raíz (<html>). rem es más predecible. C) Los porcentajes se adaptan al contenedor padre, mientras que px son fijos y pueden causar desbordamiento en pantallas chicas.

4 Imágenes responsive

img {
    max-width: 100%;   /* la imagen nunca supera el ancho del contenedor */
    height: auto;      /* mantiene la proporción original (no se estira) */
}

Explicación: max-width: 100% hace que la imagen se reduzca si el contenedor es más chico que su tamaño original, pero nunca se estire más allá de su tamaño real. height: auto mantiene la relación de aspecto. Sin esto, la imagen desbordaría en celulares.

5 Diseñá una página adaptable

/* Estilos base mobile-first: columna */
.contenedor {
    display: flex;
    flex-direction: column;
}

/* Escritorio: dos columnas lado a lado */
@media (min-width: 769px) {
    .contenedor {
        flex-direction: row;
    }
    .columna {
        flex: 1;   /* cada columna ocupa el mismo espacio */
    }
}

Criterios: mobile-first con flex-direction: column por defecto. La media query con min-width: 769px cambia a row. También es válido usar max-width: 768px con flex-direction: column dentro de la media query.
