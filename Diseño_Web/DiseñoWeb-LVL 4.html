Aprendiendo a crear formularios interactivos para recibir información del usuario

1 El Contenedor de Interacción (<form>)

📥
Formularios (<form>): Es el área destinada a recolectar datos. Todo cuadro de texto, casilla de selección o botón de envío que pongamos en la pantalla debe estar encerrado por la etiqueta principal <form> para que los datos puedan agruparse y procesarse juntos.

Ejemplo de Formulario Completo con Botón:

Para procesar el formulario, agregamos al final la etiqueta de botón de envío:

<form>
  <!-- Aquí van los cuadros de entrada de texto -->
  <button type="submit">Enviar Registro</button>
</form>

2 La Versatilidad de la Etiqueta <input>

La etiqueta <input> es una etiqueta huérfana (no se cierra). Su comportamiento cambia por completo según el valor que le asignemos a su atributo type:

📝
type="text"

Crea un cuadro de texto común para datos como nombres o usuarios.

🔒
type="password"

Oculta los caracteres con puntos negros por seguridad.

🔢
type="number"

Solo permite el ingreso de caracteres numéricos.

💬
placeholder="..."

Atributo que muestra un texto gris de pista dentro del cuadro antes de escribir.

Ejemplos visuales:

<input type="text" placeholder="Ingresá tu nombre de usuario">
<input type="password" placeholder="Escribí tu clave secreta">
<input type="number" placeholder="Ingresá tu edad">
