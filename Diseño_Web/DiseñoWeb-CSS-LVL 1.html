Clase 6: Dando Estilo con CSS Nivel 6

Selectores, colores y fuentes

1 ¿Qué es CSS?

💡
CSS (Cascading Style Sheets): Es el lenguaje de diseño de la web. Mientras que HTML define qué contenido mostrar, CSS define cómo se ve ese contenido. CSS controla colores, fuentes, tamaños, márgenes, posiciones y mucho más. CSS no es un lenguaje de marcado, es un lenguaje de estilos.

CSS funciona mediante reglas. Cada regla tiene un selector (a qué elemento apunta) y un bloque de declaraciones (qué propiedades cambiar).

2 Selectores: apuntando a los elementos

Los selectores le dicen a CSS a qué elementos HTML aplicar los estilos. Hay tres tipos fundamentales:

🏷️
Selector de etiqueta

Selecciona todos los elementos de ese tipo. Ej: p {} aplica a todos los <p>.

📌
Selector de clase

Selecciona elementos con esa clase. Se escribe con un punto. Ej: .destacado {}

🆔
Selector de ID

Selecciona un elemento único por su id. Se escribe con numeral. Ej: #encabezado {}

Ejemplo de los tres selectores:

/* Selector de etiqueta: aplica a TODOS los párrafos */
p {
    color: blue;
}

/* Selector de clase: aplica a elementos con class="destacado" */
.destacado {
    background-color: yellow;
}

/* Selector de ID: aplica al elemento con id="titulo-principal" */
#titulo-principal {
    font-size: 32px;
}

3 Colores en CSS

CSS ofrece varias formas de definir colores. Las más comunes son:

🔤
Nombres de color

Palabras clave como red, blue, green, tomato. Hay 140 nombres predefinidos.

#️⃣
Hexadecimal

Se escribe con # seguido de 6 caracteres. Ej: #ff0000 (rojo), #00ff00 (verde), #0000ff (azul).

🎛️
RGB / RGBA

Valores de rojo, verde y azul (0-255). Ej: rgb(255, 0, 0). Con rgba() agregás transparencia.

Ejemplo: mismo color, distintas formas:

/* Estas tres reglas producen el mismo color rojo */
h1 {
    color: red;                 /* nombre */
    color: #ff0000;             /* hexadecimal */
    color: rgb(255, 0, 0);      /* rgb */
}

4 Fuentes y texto

CSS permite controlar completamente la apariencia del texto con propiedades específicas:

🔤
font-family

Define el tipo de letra. Ej: font-family: Arial, sans-serif;. Se pueden listar varias como respaldo.

📏
font-size

Controla el tamaño de la fuente. Ej: font-size: 18px; o font-size: 1.2em;.

↔️
text-align

Alinea el texto: left, center, right o justify.

🎨
color

Cambia el color del texto. No confundir con background-color que cambia el fondo.

Ejemplo: párrafo con estilos:

p {
    font-family: 'Georgia', serif;
    font-size: 16px;
    text-align: justify;
    color: #333333;
}
