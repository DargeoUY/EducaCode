2 getElementById() en la práctica

A) document.getElementById("saludo")

B) document.getElementById("despedida")

C) Devuelve null (nada, vacío). Si intentamos modificar .innerHTML sobre null, el programa arrojará un error: "Cannot read property 'innerHTML' of null".

3 Cambiando contenido con innerHTML

A)
function cambiar() {
    document.getElementById("titulo").innerHTML = "Nuevo título";
}

B) .innerHTML interpreta etiquetas HTML dentro del texto (permite incluir negrita, enlaces, etc.). .textContent trata todo como texto plano y no interpreta HTML. C) Se usaría .innerHTML, porque la etiqueta <strong> debe ser interpretada como HTML para que la palabra aparezca en negrita.

4 Modificando estilos desde JavaScript

function cambiarColor() {
    document.getElementById("caja").style.backgroundColor = "red";
}

function cambiarTamaño() {
    document.getElementById("caja").style.width = "400px";
    document.getElementById("caja").style.height = "400px";
}

Criterios: usar .style.backgroundColor (no confundir con .style.color que cambia el color del texto). Las unidades px son obligatorias para width y height.

5 Integrador: botón mágico

<h1 id="mensaje">Esperando...</h1>
<button onclick="activar()">Activar</button>

<script>
function activar() {
    let h1 = document.getElementById("mensaje");
    h1.innerHTML = "¡Activado!";
    h1.style.backgroundColor = "green";
    alert("¡Completado!");
    console.log("Botón presionado a las " + new Date());
}
</script>

Criterios: obtener el elemento una sola vez con getElementById (o dos veces). Usar .innerHTML para cambiar texto. Usar .style.backgroundColor para el fondo. El alert y console.log son directos. new Date() devuelve la fecha y hora actual.
