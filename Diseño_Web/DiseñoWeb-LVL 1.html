1 ¿Qué es HTML?

💡
HTML (HyperText Markup Language): Es el lenguaje con el que se construyen todas las páginas web. Funciona mediante etiquetas que le dicen al navegador cómo mostrar el contenido. Cada página web que visitás está hecha con HTML.

HTML no es un lenguaje de programación, es un lenguaje de marcado. Esto significa que su función es "marcar" o "etiquetar" el contenido para darle estructura y significado.

2 La Estructura Básica de un Documento

Todo archivo HTML debe seguir una estructura obligatoria. Es como el esqueleto de una persona: sin él, ¡la página se desmorona!

📄
<!DOCTYPE html>

Declaración obligatoria al inicio. Le avisa al navegador que es un documento HTML5 moderno.

🏠
<html>

Es la etiqueta raíz. Todo el contenido de la página debe vivir dentro de ella.

🧠
<head>

Contiene información técnica: el título de la pestaña, configuraciones y estilos. No se ve en la pantalla.

👁️
<body>

Dentro del body va todo lo que el usuario ve en la pantalla: textos, imágenes, botones, etc.

Ejemplo de estructura mínima:

<!DOCTYPE html>
<html>
  <head>
    <title>Mi primera web</title>
  </head>
  <body>
    <!-- Todo lo visible va aquí -->
  </body>
</html>

3 Etiquetas de Texto: Títulos y Párrafos

Las etiquetas más importantes para escribir contenido son los encabezados y los párrafos:

📰
<h1> a <h6>

Encabezados o títulos. h1 es el más grande e importante, h6 el más pequeño. Solo debe haber un h1 por página.

📝
<p>

Define un párrafo de texto. El navegador agrega automáticamente un espacio antes y después de cada párrafo.

Ejemplo de títulos y párrafo:

<h1>Bienvenidos a mi sitio</h1>
<p>Este es mi primer párrafo en HTML. ¡Qué emoción!</p>
<h2>Sobre mí</h2>
<p>Me gusta aprender a crear páginas web.</p>

4 Regla de Oro: Apertura y Cierre

⚠️
La mayoría de las etiquetas HTML vienen en pares: una etiqueta de apertura <etiqueta> y una de cierre </etiqueta>. El contenido va entre ambas. Si te olvidás de cerrar una etiqueta, ¡el navegador se confunde y la página se rompe!

Existen algunas etiquetas huérfanas que no necesitan cierre (como <br> para salto de línea o <img> para imágenes), pero son la excepción, no la regla.
