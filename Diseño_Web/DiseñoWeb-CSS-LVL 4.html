Clase 9: Diseño Responsive Nivel 9

Media queries y diseño adaptable

1 ¿Qué es Diseño Responsive?

💡
El diseño responsive es una técnica que permite que una misma página web se vea bien en cualquier dispositivo: celular, tablet, laptop o monitor grande. La página se adapta al tamaño de la pantalla automáticamente. La filosofía recomendada hoy es mobile-first: diseñar primero para pantallas chicas y luego ir agregando estilos para pantallas más grandes.

Sin diseño responsive, una página que se ve bien en una computadora puede ser ilegible en un celular (texto minúsculo, scroll horizontal, botones inclickeables).

2 Media Queries

Las media queries son la herramienta principal del diseño responsive. Permiten aplicar estilos CSS solo cuando se cumple una condición, generalmente relacionada con el ancho de la pantalla.

Ejemplo: cambiar el fondo según el tamaño de pantalla:

/* Estilos para pantallas grandes (escritorio) */
body {
    background-color: lightblue;
}

/* Cuando la pantalla sea menor a 600px (móvil) */
@media screen and (max-width: 600px) {
    body {
        background-color: lightcoral;
    }
}

¿Cómo leerlo? La regla dentro de @media se aplica solo cuando el ancho de la pantalla es máximo 600px. Si la pantalla es más grande, se ignora y se usa el estilo por defecto.

Puntos de quiebre (breakpoints) comunes:

/* Móviles */
@media (max-width: 600px) { ... }

/* Tablets */
@media (max-width: 768px) { ... }

/* Laptops */
@media (max-width: 1024px) { ... }

3 Unidades relativas

Para hacer un diseño responsive, es mejor usar unidades relativas en lugar de píxeles fijos:

📊
% (porcentaje)

Relativo al elemento padre. Ej: width: 80%; — ocupa el 80% del ancho del contenedor.

📱
vw / vh

Viewport Width/Height. Relativo al ancho/alto de la ventana del navegador. Ej: width: 100vw; ocupa todo el ancho visible.

🔤
em / rem

Relativo al tamaño de fuente. em es relativo al padre; rem es relativo al elemento raíz (<html>).

Ejemplo: anchos responsive:

/* Malo: ancho fijo que no se adapta */
.contenedor {
    width: 1200px;   /* se desborda en celulares */
}

/* Bueno: ancho relativo que se adapta */
.contenedor {
    width: 90%;            /* ocupa el 90% del padre */
    max-width: 1200px;     /* pero nunca más de 1200px */
}

4 Imágenes y videos responsive

Las imágenes y videos también deben ser responsive para que no desborden su contenedor en pantallas chicas:

La regla de oro para imágenes responsive:

img {
    max-width: 100%;    /* la imagen nunca supera el ancho de su contenedor */
    height: auto;       /* mantiene la proporción original */
}

/* Lo mismo aplica para videos (iframes de YouTube, etc.) */
video, iframe {
    max-width: 100%;
    height: auto;
}

Con estas dos líneas, cualquier imagen se adapta automáticamente al ancho disponible. Si el contenedor mide 400px, la imagen mide 400px. Si mide 800px, la imagen crece hasta 800px (o su tamaño original, el que sea menor).
