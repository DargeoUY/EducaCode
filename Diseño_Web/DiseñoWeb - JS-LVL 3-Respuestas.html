1 if / else básico

let temperatura = 25;

if (temperatura > 30) {
    console.log("Hace calor");
} else {
    console.log("Está fresco");
}

Con temperatura = 25: muestra "Está fresco". Con temperatura = 35: muestra "Hace calor". Con temperatura = 10: muestra "Está fresco".

2 Operadores de comparación

A) true | B) false (distinto tipo: number vs string) | C) true | D) false | E) true | F) true | G) false | H) true | I) false

Pregunta extra: 10 === "10" da false porque === compara valor y tipo. 10 es number y "10" es string. Son de tipos diferentes, por eso no son estrictamente iguales. Si usáramos == (doble igual), daría true porque convierte tipos automáticamente, pero === es más seguro.

3 Operadores lógicos (&& y ||)

A) true (ambas son true) | B) false (la primera es false) | C) true (la segunda es true) | D) true (la primera es true) | E) false (la segunda es false) | F) true (una es true)

let nota = 8;

if (nota >= 1 && nota <= 12) {
    console.log("Nota válida");
}

4 if / else if / else

let edad = 15;

if (edad < 13) {
    console.log("Niñez");
} else if (edad < 18) {
    console.log("Adolescencia");
} else if (edad < 65) {
    console.log("Adultez");
} else {
    console.log("Tercera edad");
}

edad=10 → Niñez | edad=15 → Adolescencia | edad=30 → Adultez | edad=70 → Tercera edad

Importante: el orden de los else if es clave. Si pusiéramos edad < 65 primero, los menores de 13 también entrarían ahí. Hay que ordenar de más restrictivo a menos.

5 Integrador: semáforo

let colorSemaforo = "rojo";

if (colorSemaforo === "rojo") {
    console.log("Detenerse");
} else if (colorSemaforo === "amarillo") {
    console.log("Precaución");
} else if (colorSemaforo === "verde") {
    console.log("Avanzar");
} else {
    console.log("Color inválido");
}

Criterios: usar === para comparar strings. Cubrir los 3 casos válidos más el caso por defecto con else. El orden de los else if no importa en este caso porque las condiciones son mutuamente excluyentes.
