Clase 3: Estructurando Datos Nivel 3

Aprendiendo a organizar información compleja mediante filas, columnas y celdas

1 Anatomía de una Tabla HTML

📊
El Contenedor Padre (<table>): Para dibujar una grilla o tabla de datos en la web, todo el contenido debe estar envuelto por la etiqueta <table>. Las tablas no se arman de forma libre; se construyen estrictamente fila por fila de arriba hacia abajo.

2 Las Tres Etiquetas de la Grilla

Para dar vida a las filas y columnas del documento, combinamos tres etiquetas fundamentales de manera jerárquica:

↔️
<tr>

Table Row: Define una fila completa horizontal. Es el contenedor de las celdas.

🏷️
<th>

Table Header: Celda de encabezado. El navegador la muestra en negrita y centrada.

📋
<td>

Table Data: Celda de contenido común dentro de la fila. Texto normal alineado a la izquierda.

Ejemplo de tabla completa:

<table>
  <tr>
    <th>Nombre</th>
    <th>Edad</th>
    <th>Nota</th>
  </tr>
  <tr>
    <td>Ana</td>
    <td>16</td>
    <td>9.5</td>
  </tr>
</table>

3 Regla de Construcción

🧱
Orden jerárquico obligatorio: <table> → <tr> → <th> o <td>. Nunca se puede poner un <td> directamente dentro de <table> sin pasar antes por <tr>. Si rompés esta jerarquía, ¡la tabla no se dibuja correctamente!
