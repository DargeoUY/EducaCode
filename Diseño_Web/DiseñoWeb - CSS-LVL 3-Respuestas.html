Diseño Web CSS Nivel 3 — Respuestas Docente

Clave de corrección para los ejercicios de CSS Nivel 3

🔒 SOLO DOCENTE — Respuestas del CSS Nivel 3.

1 Contenedor Flex

.contenedor {
    display: flex;
}

Efecto: todos los hijos directos se convierten en items flex y se ordenan en una fila horizontal (por defecto). Pueden alinearse y distribuirse fácilmente con justify-content y align-items.

2 Dirección del flujo

A) .contenedor { display: flex; flex-direction: row; }
B) .contenedor { display: flex; flex-direction: column; }
C) .contenedor { display: flex; flex-direction: row-reverse; }

Criterios: A debe usar row (o no especificar, ya que es el default). B debe usar column. C debe usar row-reverse.

3 Alineación horizontal

flex-start: items pegados a la izquierda. center: items centrados, espacio sobrante a los costados. space-between: primer item a la izquierda, último a la derecha, espacio equitativo entre ellos. space-around: espacio equitativo alrededor de cada item (mitad de espacio en los extremos).

Criterios: debe explicar correctamente cada valor. El dibujo es opcional pero suma.

4 Alineación vertical

.contenedor-centrado {
    display: flex;
    justify-content: center;   /* centrado horizontal */
    align-items: center;       /* centrado vertical */
    height: 400px;
}

Criterios: debe incluir display: flex, justify-content: center, align-items: center y height: 400px. Este es el patrón clásico de "centrado perfecto".

5 Navbar con Flexbox

.navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
    background-color: #333;
    color: white;
    padding: 10px 20px;
}

Criterios: debe usar display: flex, justify-content: space-between, align-items: center, y los colores especificados. El padding es opcional pero recomendable.
