1 Capas del Box Model

De adentro hacia afuera: content (contenido, controlado por width/height) → padding (relleno interno) → border (borde) → margin (margen externo).

Criterios: el orden debe ser exacto. Valorar si el estudiante dibuja un esquema visual y menciona cada propiedad CSS asociada.

2 Margin vs Padding

A) div { margin: 20px; }
B) div { padding: 15px 30px; }   /* 15px arriba/abajo, 30px izquierda/derecha */

Criterios: A usa margin. B usa la forma abreviada de padding con 2 valores (vertical horizontal). También es válido escribir padding: 15px 30px 15px 30px;.

3 Bordes creativos

A) div { border: 3px solid blue; }
B) div { border: 2px dashed green; }
C) div { border: 1px dotted red; border-radius: 8px; }

Criterios: cada regla debe incluir el ancho, estilo y color correctos. C debe incluir border-radius.

4 Dimensiones

A) width: 300px es un valor fijo (no cambia si se achica la ventana). width: 50% es un valor relativo al elemento padre (se adapta al tamaño del contenedor). B) Si no se especifica height, el elemento toma la altura necesaria para contener su contenido (height: auto por defecto). El alto se ajusta automáticamente.

5 Maquetá una tarjeta

.tarjeta {
    width: 300px;
    padding: 20px;
    border: 1px solid gray;
    border-radius: 10px;
    margin-bottom: 15px;
}

Criterios: debe incluir las 5 propiedades con los valores especificados. El nombre de la clase puede variar.
