Clase 2: Conectando la Web Nivel 2

Aprendiendo a usar atributos para añadir enlaces, imágenes y listas organizadas

1 Los Atributos y los Hipervínculos

🔗
Enlaces (<a>): Para conectar nuestra página con el resto del mundo usamos la etiqueta de anclaje. Pero no viaja sola; necesita un atributo llamado href que le dice al navegador la dirección web (URL) exacta de destino.

Los atributos son palabras especiales que se escriben dentro de la etiqueta de apertura para darle instrucciones adicionales al navegador. Siempre tienen el formato atributo="valor".

Ejemplo de enlace:

<a href="https://www.google.com">Ir a Google</a>

2 Elementos Visuales: Las Imágenes

La etiqueta <img> es una etiqueta huérfana (no tiene etiqueta de cierre). Utiliza dos atributos obligatorios para funcionar correctamente:

📁
src

Indica la ruta o nombre del archivo de imagen (ej. "foto.jpg"). Es obligatorio.

🖼️
alt

Texto alternativo que describe la imagen si falla la carga o para lectores de pantalla.

Ejemplo de imagen:

<img src="avatar.png" alt="Foto de perfil del usuario">

3 Organización de Datos: Listas

Para agrupar elementos ordenadamente en la pantalla, HTML nos ofrece dos estructuras principales. Ambas usan la etiqueta interna <li> para cada ítem:

📋
<ul>

Lista desordenada. Muestra los elementos con viñetas de puntos, sin orden numérico.

🔢
<ol>

Lista ordenada. El navegador asigna automáticamente un número secuencial (1, 2, 3...).

Ejemplo de lista ordenada:

<ol>
  <li>Encender la computadora</li>
  <li>Abrir el navegador</li>
  <li>Escribir código HTML</li>
</ol>
