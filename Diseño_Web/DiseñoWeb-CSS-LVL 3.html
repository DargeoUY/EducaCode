Clase 8: Diseño con Flexbox Nivel 8

Display flex, alineación y distribución

1 ¿Qué es Flexbox?

💡
Flexbox (Flexible Box Layout) es un sistema de diseño unidimensional que permite distribuir y alinear elementos fácilmente dentro de un contenedor, incluso cuando su tamaño es dinámico. Se basa en dos roles: un contenedor flex (el padre con display: flex;) y los items flex (los hijos directos).

Antes de Flexbox, centrar un elemento verticalmente era muy complicado. Con Flexbox se hace con una sola línea. Hoy es la herramienta estándar para crear layouts modernos.

2 Dirección del flujo

La propiedad flex-direction define en qué dirección se ordenan los items dentro del contenedor flex:

➡️
row

Valor por defecto. Los items se colocan en fila, de izquierda a derecha.

⬇️
column

Los items se colocan en columna, de arriba hacia abajo.

⬅️
row-reverse

Igual que row pero en orden inverso: de derecha a izquierda.

Ejemplo de flex-direction:

.contenedor {
    display: flex;
    flex-direction: row;        /* items en fila horizontal */
}

.contenedor-vertical {
    display: flex;
    flex-direction: column;     /* items en columna vertical */
}

3 Alineación horizontal

La propiedad justify-content controla cómo se distribuyen los items a lo largo del eje principal (horizontal cuando es row, vertical cuando es column):

◀️
flex-start

Los items se agrupan al inicio del contenedor. Es el valor por defecto.

⚫
center

Los items se centran horizontalmente dentro del contenedor.

↔️
space-between

El espacio sobrante se distribuye entre los items. El primero y el último quedan pegados a los bordes.

🔲
space-around

El espacio sobrante se distribuye alrededor de cada item, incluyendo antes del primero y después del último.

Ejemplo: centrar items horizontalmente:

.contenedor {
    display: flex;
    justify-content: center;   /* items centrados horizontalmente */
}

4 Alineación vertical

La propiedad align-items controla cómo se alinean los items a lo largo del eje cruzado (vertical cuando es row, horizontal cuando es column):

📏
stretch

Valor por defecto. Los items se estiran para ocupar toda la altura del contenedor.

⚫
center

Los items se centran verticalmente dentro del contenedor.

⬆️
flex-start

Los items se alinean al inicio del eje cruzado (arriba).

⬇️
flex-end

Los items se alinean al final del eje cruzado (abajo).

Ejemplo: centrado perfecto (horizontal + vertical):

.contenedor-centrado {
    display: flex;
    justify-content: center;   /* centrado horizontal */
    align-items: center;       /* centrado vertical */
    height: 300px;
}
