1 El bucle for

A) for (let i = 1; i <= 10; i++) { console.log(i); }

B) for (let i = 2; i <= 20; i += 2) { console.log(i); }

C) for (let i = 1; i <= 10; i++) {
       console.log("5 x " + i + " = " + (5 * i));
   }

D) for (let i = 10; i >= 1; i--) { console.log(i); }
   console.log("¡Despegue!");

Criterios: A) inicio en 1, condición <= 10. B) incremento de 2 en 2 (i += 2). C) multiplicar 5 * i en cada vuelta. D) cuenta regresiva: i-- (decremento) y i >= 1. El "¡Despegue!" va fuera del for.

2 El bucle while

A) let i = 1; while (i <= 10) { console.log(i); i++; }

B) let i = 2; while (i <= 20) { console.log(i); i += 2; }

C) let i = 1; while (i <= 10) {
       console.log("5 x " + i + " = " + (5 * i)); i++;
   }

D) let i = 10; while (i >= 1) { console.log(i); i--; }
   console.log("¡Despegue!");

Pregunta: while conviene cuando no sabemos cuántas vueltas se necesitan (ej: esperar a que el usuario ingrese un valor válido). for es mejor cuando el número de repeticiones es conocido de antemano.

3 Arrays: declaración y acceso

A) Tiene 5 elementos. Se usa la propiedad .length: colores.length devuelve 5.

B) colores[0] = "rojo" | colores[3] = "amarillo"

C) colores[10] devuelve undefined (no definido), porque no hay elemento en esa posición.

D) colores[2] = "naranja";

E) colores.push("blanco"); — ahora el array tiene 6 elementos.

4 Recorriendo arrays con for

let alumnos = ["Ana", "Bruno", "Carla", "Diego", "Elena"];

// Recorrer todos:
for (let i = 0; i < alumnos.length; i++) {
    console.log("Alumno " + i + ": " + alumnos[i]);
}

// Solo los que empiezan con vocal:
for (let i = 0; i < alumnos.length; i++) {
    let primeraLetra = alumnos[i][0].toLowerCase();
    if (primeraLetra === "a" || primeraLetra === "e" ||
        primeraLetra === "i" || primeraLetra === "o" ||
        primeraLetra === "u") {
        console.log(alumnos[i]);
    }
}
// Resultado: Ana, Elena

5 Integrador: lista de compras

let compras = ["leche", "pan", "huevos", "arroz", "fideos"];

console.log("Mi lista de compras:");

for (let i = 0; i < compras.length; i++) {
    console.log((i + 1) + ". " + compras[i]);
}

console.log("Total de productos: " + compras.length);

Pregunta extra: se usa compras.push("pan"); para agregar "pan" al final del array.

Criterios: usar .length como límite del for. Numerar desde 1 (i + 1) porque los índices empiezan en 0. El total es compras.length. Para agregar elementos, .push() es el método correcto.
