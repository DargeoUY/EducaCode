Clase 7: El Modelo de Cajas Nivel 7

Margin, padding, border y dimensiones

1 El Modelo de Cajas (Box Model)

💡
Todo elemento HTML es una caja rectangular. Cada caja está compuesta por cuatro capas concéntricas: content (contenido) → padding (relleno interno) → border (borde) → margin (margen externo). Entender este modelo es clave para maquetar páginas web correctamente.

Imaginá una foto en un portarretratos: la foto es el content, el cartón alrededor es el padding, el marco es el border y el espacio hasta la pared es el margin.

2 Margin y Padding

Margin y padding son dos propiedades fundamentales pero con propósitos muy distintos:

⬆️
margin

Espacio EXTERNO: separa el elemento de otros elementos. No tiene color de fondo. Se puede aplicar a los cuatro lados: margin-top, margin-right, margin-bottom, margin-left.

⬇️
padding

Espacio INTERNO: separa el contenido del borde del elemento. Sí tiene el color de fondo del elemento. También se controla por lados: padding-top, padding-right, etc.

Ejemplo: div con margin y padding:

div {
    margin: 20px;       /* espacio externo: 20px a cada lado */
    padding: 15px;      /* espacio interno: 15px a cada lado */
    background: lightblue;
}

/* Forma abreviada con 4 valores: arriba derecha abajo izquierda */
div {
    margin: 10px 20px 10px 20px;
    padding: 5px 15px 5px 15px;
}

3 Bordes

La propiedad border permite definir el borde de un elemento con tres componentes: ancho, estilo y color.

━━
border: solid

Borde sólido continuo. Es el más común. Ej: border: 2px solid black;

┅┅
border: dashed

Borde con línea discontinua. Ej: border: 2px dashed gray;

···
border: dotted

Borde con puntos. Ej: border: 2px dotted blue;

⭕
border-radius

Redondea las esquinas del borde. Ej: border-radius: 10px; ¡Con 50% hacés un círculo!

Ejemplo de bordes con distintos estilos:

.solido {
    border: 3px solid red;
}

.discontinuo {
    border: 2px dashed green;
}

.redondeado {
    border: 2px solid blue;
    border-radius: 12px;
}

4 Width y Height

Las propiedades width (ancho) y height (alto) controlan las dimensiones de un elemento. Se pueden usar valores en píxeles o porcentajes.

📏
Píxeles (px)

Valor fijo que no cambia. Ej: width: 300px; — el elemento mide 300px sin importar el tamaño de la pantalla.

📊
Porcentajes (%)

Valor relativo al elemento padre. Ej: width: 50%; — el elemento ocupa la mitad del ancho de su contenedor.

Ejemplo: dimensiones con px y %:

.caja-fija {
    width: 300px;      /* ancho fijo de 300 píxeles */
    height: 200px;     /* alto fijo de 200 píxeles */
}

.caja-flexible {
    width: 50%;        /* ocupa la mitad del ancho del padre */
    height: auto;      /* el alto se ajusta al contenido */
}
