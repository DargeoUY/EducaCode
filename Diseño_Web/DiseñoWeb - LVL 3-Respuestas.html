Clave de corrección para los ejercicios

🔒 SOLO DOCENTE — Respuestas del Nivel 3.

1 Crear una tabla

<table>
  <tr>
    <th>Nombre</th>
    <th>Edad</th>
  </tr>
  <tr>
    <td>Ana</td>
    <td>16</td>
  </tr>
  <tr>
    <td>Luis</td>
    <td>17</td>
  </tr>
</table>

Criterios: encabezados con <th>, datos con <td>, cada fila en <tr>.

2 Celda de encabezado

<th> (Table Header). El navegador la muestra en negrita y centrada automáticamente. <td> (Table Data) muestra texto normal alineado a la izquierda.

3 Corregir el error

Falta <tr> entre <table> y <td>. La jerarquía es: <table> → <tr> → <td>. No se puede poner un <td> directamente dentro de <table>.

<table>
  <tr>
    <td>Hola</td>
  </tr>
</table>

4 Contar filas

Tiene 3 filas. Cada <tr> representa una fila. Como hay 3 etiquetas <tr>, la tabla tiene 3 filas.

5 Jerarquía de la tabla

<table> → <tr> (fila) → <th> (encabezado) o <td> (dato). Nunca se puede invertir este orden ni saltear niveles.
